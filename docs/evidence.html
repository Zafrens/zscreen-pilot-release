Evidence behind the results

The source tables below make the headline results and nominated compounds inspectable. Download the rows, compare the populations, and follow the provenance manifest to the source analysis. Tables retain compound identifiers and measured results; structure images and SMILES/scaffold fields are withheld. Download hashes refer to the sanitized files; original source hashes are labeled separately.

Source release. The full pilot dataset is on Hugging Face (Zafrens/zscreen-pilot) with per-file SHA-256 manifests; an interactive Functional Drug Atlas covers a portion of it.

How to read the headline numbers

Scale

162,914 compounds and 190,699 compound–context profiles describe the pilot dataset analyzed in the white paper, not the platform’s capacity.

Prediction

On SciPlex3, the Z-Screen-pretrained conditional Chemprop reaches DE50 response r = 0.593 versus 0.449 for a scratch run trained to its validation optimum (58 epochs). A scratch run stopped at the pretrained model’s 7 epochs reaches 0.618, so the +0.144 comparison does not isolate a pretraining advantage in response correlation. Pretraining retains higher DE50 profile R² (0.811 versus 0.794) and lower RMSE (0.177 versus 0.184).

Discovery

2,626 series–target matches occupy 178 clusters; 2,229 pass the lineage-support gate, which participates in selection. Chemical discovery gives 110 matches across 51 context–series labels; 33 have both internal-control and CRISPR support, including the selected top ten.

Calibration

CIGS 0.822 is a median matched-panel rank for 17 qualified controls. MZ1 AUROC 0.799 is chromatin-class recovery in H1650. CRISPR 0.580 is a compound median across 25 matched Tier-1 controls.

Controls that change how a claim should be read

Training-duration control on SciPlex3The pretrained conditional Chemprop reaches DE50 response r = 0.5931 versus 0.4490 for a scratch run trained to its validation optimum (58 epochs). A scratch run stopped at the same 7 epochs as the pretrained model reaches 0.6175, so the +0.1441 comparison does not isolate a pretraining advantage in response correlation. Pretraining retains higher DE50 profile R² (0.8114 versus 0.7944) and lower response RMSE (0.1766 versus 0.1840). These saved three-seed comparisons cover 83 conditions from nine held-out drugs.
Unseen building blocksOn the same 7,544 unseen-building-block HEK293 compounds, the additive recipe model reaches mean program r = 0.3628, R² = 0.1094 and 2.624× directional enrichment, versus Chemprop 2.3.1 at 0.3367, 0.0888 and 2.534×. Both use 5,721 training and 649 validation profiles. The shared-context three-seed transformer reaches r = 0.3978 and 2.861× enrichment using eight contexts, but its mean program R² is −0.9873: ranking improves while effect-size calibration worsens.
ActiveSeq population poolingPopulation recognition improves after pooling 32 held-out wells: joint image/RNA exceeds RNA alone by +2.86 percentage points for batch 1 → 2 and +10.48 for batch 2 → 1. Single-well classification shows no consistent gain; the pooled result is a post-fit aggregation under a fixed classifier, not a learned fusion model.
